# 📌 About The Project

**DevTrack** is a full-stack project management and productivity application created specifically for developers.

The platform provides a centralized workspace where developers can organize their projects, manage tasks, track progress and keep development information structured.

Inspired by tools like **Trello**, **Jira**, **Notion**, and **GitHub Projects**, DevTrack focuses on creating a simple but powerful environment for managing software development workflows.

The main objective is to build a professional developer productivity tool while exploring modern full-stack development practices.
